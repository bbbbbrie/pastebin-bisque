---
title: ⌨️ Use pastebin-bisque
---

```shell
pastebin-bisque
```

Specify a username:

```shell
pastebin-bisque --username catstestingcode
```

Zip the results:

```shell
pastebin-bisque -z
```

Download all of the public pastes for the `catstestingcode` user and save them in a `.zip` file:

```shell
pastebin-bisque --username catstestingcode -z
```
